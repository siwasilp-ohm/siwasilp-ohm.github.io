# เครื่องมือแก้ไขสีภาพ (Color Correction Tool)

แอปพลิเคชันนี้เป็นเครื่องมือสำหรับแก้ไขสีภาพให้ถูกต้องโดยใช้ Color Checker เป็นตัวอ้างอิง สามารถทำ White Balance และ Map สีใหม่จาก Color Palette รวมถึงคำนวณระยะของภาพโดยอ้างอิงจากวงกลมบน Color Checker

## คุณสมบัติ

- อัปโหลดและแสดงภาพต้นฉบับและภาพหลังแก้ไข
- ถ่ายภาพโดยตรงจากกล้องเว็บแคมหรือกล้องมือถือ
- ตรวจจับ Color Checker ในภาพอัตโนมัติ
- ปรับแต่งสีโดยอ้างอิงจาก Color Checker
- แก้ไข Color Palette ได้ตามต้องการ
- ปรับ White Balance, Temperature และ Tint
- คำนวณระยะห่างจากกล้องโดยอ้างอิงจากวงกลมบน Color Checker
- แสดงรายละเอียดการ Map สี
- รองรับการใช้งานบน Native App

## วิธีใช้งาน

1. อัปโหลดภาพที่มี Color Checker หรือถ่ายภาพจากกล้อง
   - สำหรับการอัปโหลดภาพ: คลิกที่ปุ่ม "เลือกภาพ"
   - สำหรับการถ่ายภาพจากกล้อง: คลิกที่ปุ่ม "ถ่ายภาพจากกล้อง" แล้วอนุญาตให้เว็บไซต์เข้าถึงกล้อง
2. คลิกปุ่ม "ตรวจจับ Color Checker" เพื่อให้ระบบตรวจจับ Color Checker ในภาพ
3. คลิกปุ่ม "ปรับแต่งสีอัตโนมัติ" เพื่อให้ระบบปรับแต่งสีโดยอัตโนมัติ
4. ปรับแต่ง White Balance, Temperature และ Tint ตามต้องการ
5. คลิกที่สีใน Color Palette เพื่อแก้ไขค่าสี
6. ดูรายละเอียดการ Map สีและระยะห่างจากกล้องที่คำนวณได้

## การแก้ไข Color Palette

1. คลิกที่สีใน Color Palette ที่ต้องการแก้ไข
2. ปรับค่า RGB หรือ HEX ตามต้องการ
3. คลิกปุ่ม "บันทึก" เพื่อบันทึกการเปลี่ยนแปลง

## การคำนวณระยะ

ระบบจะคำนวณระยะห่างจากกล้องโดยอ้างอิงจากวงกลมบนซ้ายและวงกลมบนขวาของ Color Checker โดยใช้ความกว้างจริงของ Color Checker (24 ซม.) เป็นตัวอ้างอิง

## เทคโนโลยีที่ใช้

- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API สำหรับการประมวลผลภาพ

## การพัฒนาต่อ

- เพิ่มการตรวจจับ Color Checker ที่แม่นยำมากขึ้นโดยใช้ Computer Vision
- เพิ่มอัลกอริทึมการ Map สีที่ซับซ้อนมากขึ้น
- เพิ่มการบันทึกและโหลดการตั้งค่า
- เพิ่มการส่งออกภาพในรูปแบบต่างๆ
- พัฒนาเป็น Native App สำหรับ iOS และ Android
